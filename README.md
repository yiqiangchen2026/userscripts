# Userscripts

公开分享的油猴脚本合集。每个脚本放在 `scripts/` 下独立维护，后续会继续新增。

## 脚本列表

| 脚本 | 适用页面 | 功能 |
| --- | --- | --- |
| [OKX LP 区间快捷设置](scripts/okx/okx-lp-range.user.js) | OKX Web3 上 X Layer 的 Uniswap V3 USDC、USDG 交易对页面 | 按当前价格填写偏稳定币的 LP 价格区间，并读取页面实际区间进行核对。 |

## 安装

1. 安装 Tampermonkey 浏览器扩展。
2. 打开 [OKX LP 脚本原始文件](https://raw.githubusercontent.com/yiqiangchen2026/userscripts/main/scripts/okx/okx-lp-range.user.js)。如果 Tampermonkey 弹出安装页，检查脚本内容后点击安装；如果没有弹出，在 Tampermonkey 中新建脚本，粘贴文件内容并保存。
3. 打开支持的 OKX 页面并刷新，在页面右下角找到“LP 区间快捷设置”。

更新时重新安装最新版，或用最新文件内容替换旧脚本并保存。编辑脚本时只保留一个 Tampermonkey 标签页，避免修改冲突。

## OKX LP 脚本怎么用

默认目标是当前价格下方 7.8%、上方 0.25%。点击“按当前价设置”后，脚本会填写价格，并尝试按 OKX 的价格档位校准。校验完成后，脚本还会点击一次图表右上角的“缩小”，让区间更容易完整显示。只有页面实际显示的总区间宽度大于 8.01%，且上方距离在 0.2%～0.3% 之间时，脚本才会显示成功。

脚本只修改价格区间，不填写金额，也不提交申购。点击按钮后请核对页面实际价格、代币比例及当前活动规则，再自行决定是否申购。价格距离不等于初始代币的资产占比；脚本显示成功也不代表获得奖励资格。

当前脚本仅匹配 URL 中包含 `-usdc-` 或 `-usdg-` 的上述 OKX 产品页面，并会检查页面报价方向。不适用于其他交易对。
