# Userscripts

个人使用的油猴脚本集合。每个脚本放在 `scripts/` 下独立维护；以后可以按网站新增目录。

## 现有脚本

| 脚本 | 用途 |
| --- | --- |
| [OKX LP 区间快捷设置](scripts/okx/okx-lp-range.user.js) | 在 OKX X Layer 的 Uniswap V3 USDC、USDG 交易对页面，按现价填写偏稳定币的价格区间，并核对页面实际区间。 |

## 安装与更新

1. 在 Tampermonkey 中新建脚本，粘贴 `.user.js` 文件内容并保存。
2. 更新时替换旧脚本内容并保存。请关闭其他正在编辑同一脚本的标签页，避免 Tampermonkey 的修改冲突提示。
3. 刷新目标页面，再检查脚本的实际结果。

## OKX LP 脚本说明

默认目标为现价下方 7.8%、上方 0.25%。OKX 会把输入价格吸附到池子的价格档位，因此脚本在填写后读取实际上下限；只在总宽度严格大于 8%、上方价格距离处于 0.2%～0.3% 时显示成功。

脚本只填写价格，不填写金额，也不提交申购。价格距离不等于初始股票代币的资产占比。奖励资格以所参与活动的当期规则为准。

## 后续新增脚本

- 每个脚本使用独立的 `.user.js` 文件及 `@namespace`。
- 修改现有脚本时增加 `@version`，并在真实目标页面核对匹配范围和关键操作。
- 将新的脚本及简短用途加入上面的表格。
